# 有效 gate 的512维 Ranking 对照

按用户确认，保持既有方法，只做512维 XOR/Ring 的排名对照：新增10月9日报告定义的有效 gate 参照，LassoNet 和现有一阶加二阶方案不改训练方法，直接复用同一批512维数据上的已核验结果。本轮没有改原评分实现、调参、下游重训或增加候选方法。

## 结果

每任务1000样本、普通不打乱六折，同一保存的数据、列置换及相关特征真值；每折 Top-2，Recall@2 为找回两个真实特征的比例。下表为百分数，Macro 等权平均 XOR/Ring。

| 方法 | XOR | Ring | 两任务 Macro | AP |
| --- | ---: | ---: | ---: | ---: |
| 现有方案：一阶＋经验 Fisher | 100.00 | 16.67 | 58.33 | 62.36 |
| 有效 gate：10月报告参照 | 0.00 | 100.00 | 50.00 | 50.42 |
| LassoNet：现有固定设置 | 83.33 | 0.00 | 41.67 | 42.02 |

有效 gate 参照的 Ring 六折全部选中两个相关特征，XOR 六折均未选中。方向上重现了 [10月9日实验报告](https://my.feishu.cn/docx/AXzzdP73Go5VhUxIdw7coClanEb) 的高维困难：历史512维 Ring 为95.8%，XOR仅4.2%。本次并非历史运行的逐参数复现；当前12折来自一个新配对实例，历史每格是两个实例×六折，不能把0%与4.2%的差异当成退步或精确数值复现失败。

当前一阶＋Fisher的两任务均值更高，但其 Ring 明显弱于有效 gate。不同方法训练配方和表示本来就不同，本表不能将差异全部归因于评分。尤其本轮没有把外部 score 插入 canonical RatioNorm，不能称为“在相同有效 gate 骨干上换 score”的消融。

此前同数据公开 raw-gate 原列范数参照为 XOR100%、Ring41.67%、两任务均值70.83%，仍高于现有一阶＋Fisher的58.33%。该历史对照见 [此前512维表](<2026年11月28日 Baseline 修复与512维复核.md>)，因此本表也不支持一阶＋二阶总优于原方案。

## 保持了哪些方法定义

有效 gate 只增加 [独立模型与训练入口](../../src/effective_gate.py) 和 [排名运行入口](../../experiments/ranking_effective_gate.py)，没有修改既有 raw-gate、LassoNet 或 Fisher 实现。

- 两层32单元、ReLU、二分类BCE；每个原始特征的线性/平方通道共享一个 raw gate s。线性权重按原始维度的普通 Linear 默认方式初始化，平方权重为零，s=1
- 对线性/平方权重共同计算 a_j=√(‖U_j‖₂²+‖V_j‖₂²)，有效幅度 g_j=a_js_j；原始前向等于两个通道各乘 s 后进入各自权重。没有引入 weight normalization、重新投影权重或额外尺度参数
- 原输入按训练折标准化；平方通道由标准化输入平方，再减去训练折平方均值，不额外除以标准差。平方仅中心化沿用 [保留的最小版本记录](../research/20260920-xor-ring-thread/sources/c48e64e51045964a3c30.md)，共同父 gate 的 block 范数定义见 [历史方法对照](../research/20260920-xor-ring-thread/sources/da99f5730f69fcfd4891.md)
- 使用 [数学定义](https://dreamsoul.feishu.cn/docx/Bxa7dPa32oF4hvxwk1Pcnm3Pnvf) 的 g=z 单副本共识、全局 C、R(0)=1、canonical signed RatioNorm prox；z 初始化为 g、u=0。逐 epoch 更新 z、u，不把 z 写回 gate，不阶段重置 Adam
- 保持120轮、batch64、零 warm-up/weight decay/dropout；固定报告 trial8 的约值 C=0.003172、ρ=0.18857、lr=0.002084。没有按维数缩放 C，没有搜索或选取最佳中间 epoch，最终按 |g| 排序

近端求解器不重新实现：从仓内保留的 [工具源码](../research/20260920-xor-ring-thread/sources/2f836a8e083b6831da0a.py) 复用目标、KKT及Top-k函数，从 [已有数值候选](../research/20260920-xor-ring-thread/sources/6ed77fc604592abeabf3.py) 复用完整 canonical prox 函数；运行前核对文件哈希，函数体保持原样。该数值候选已有的正根、候选认证和舍入级目标平局规则一并保留；没有换成 shrink-plus-cubic 近似或另写新求解方法。

本入口是按已取得材料恢复的报告参照，不声称取得10月原始驱动或11月 A—L 源码。报告只给了舍入后的 trial8 参数，历史数据/种子和完整初始化驱动尚未恢复。平方结构采用报告中的共享线性/平方通道，不替换成数学附篇另一项尚未实现的 (g·x)² 扩展。

现有一阶＋Fisher保留公开 raw-gate 的500/120轮及已有 score scaling；LassoNet 保留已有32×32模型和原生稀疏路径/内部验证选模设置。这两条均直接复用 [上一轮逐折分数证据](20261128-baseline-repairs/512/verified_results.jsonl)，没有为新表再次更改训练。三者共享数据，但不声称模型、训练预算或调参预算完全相同。

## 核验与证据

12个新 checkpoint 全部重载通过，确认训练折标准化与平方均值、最终有效 gate、block列范数、非零Top-k、平方零初始化和120轮预算。1440次近端更新全部通过原求解器认证，最后一次 z 从其中心独立重算一致。将一个父 gate 人为设零后，同时改变该原始特征的线性/平方值，预测保持完全不变。针对性测试也核验了 raw factor 与有效 gate 的删除梯度矩一致。

CPU运行，避免占用其他任务正在使用的GPU；新参照12折训练总墙钟约46秒。原报告使用GPU float32，因此这里不宣称逐位恢复其训练轨迹。完整测试16项通过，独立标准库校验36条分数和三条汇总一致。测试支持实现与记录一致性，不构成恢复保证或跨种子稳健性结论。
