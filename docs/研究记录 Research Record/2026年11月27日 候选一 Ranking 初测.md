# 候选一 Ranking 初测

后续已完成[原500轮预算复现与四任务对照](<2026年11月28日 原方案复现与候选一 Ranking 对照.md>)。本文保留缩短预算初测，不与后续结果混算。

候选一已接入独立排名入口，并完成128维 XOR / Ring 的小规模配对试验。一阶加经验 Fisher 二阶尚未显示稳定优势：XOR 的三个方案均达到 recall@2=1，Ring 上二阶方案与列范数参照均为0.0833，纯一阶为0。这个结果只覆盖一份数据实例的6折、缩短训练预算，不作为完整 benchmark 或性能提升结论。

## 代码与本次修正

- `dev` 原有 `src/models.py` 只有普通 MLP，未接入 gate benchmark。本次从固定版本 `feature-selection@555ba11e8872bd6618cd721bd3b08f7128db9e6b` 的 `src/admm_input_group_wrapper.py` 选择性移植共享直接 gate、两层32宽 Mish 网络与两变量 ADMM 路径，提供 [排名模型与训练](../../src/feature_selection.py)。未引入有效幅度、逐样本 gate 或 LassoNet 候选
- [逐样本 score](../../src/feature_scores.py) 使用任务损失计算 t=g·∂ℓ/∂g，先求 mean(t²)，再构造 mean(-t+0.5t²)。最终取聚合结果的绝对值，按均值归一得到非负 scaling，stop-gradient 后进入原阈值公式。全零分数采用均匀 scaling。纯一阶采用同一映射，避免平方顺序或不同缩放方式混淆
- 评分时关闭随机 feature mask 和 dropout，恢复各子模块原来的 train/eval 标记，不污染参数 `.grad` 或随机状态。校准数据只取当前训练折内固定的128行，每10个 ADMM epoch 刷新一次，不在 score 中加入增广项、权重衰减或真值支持
- 分类损失显式区分二分类浮点标签与多分类整数标签。保存实际 gate、Z、U、ρ、优化器、标准化统计、校准行、分数矩与逐轮轨迹，辅助变量为零不冒充预测路径已硬剪枝
- 保留历史 shrink-plus-cubic 更新，同时用数值稳定的正根公式避免大系数下相消。该历史更新未证明是一般加权 L1/L2 的精确全局近端解，运行成功也不代表完成了该证明
- 本机首次启动停在 NumPy 导入，未开始训练。相同环境先导入 PyTorch 后，NumPy / scikit-learn 可正常加载，入口已采用该顺序。未安装或升级依赖

数据生成器 [feature_selection_data.py](../../src/feature_selection_data.py) 保留原文件版权与许可说明，字节来源固定到上述提交的 `src/data.py`。模型初始化、二分类和多分类的 train/eval 前向均已与固定历史模型逐元素核对一致。数据加载顺序使用独立、固定种子的生成器；本轮不是历史完整训练轨迹复现。

## 固定协议

| 项目 | 设置 |
| --- | --- |
| 数据 | 原 XOR 与 Ring 生成器，各1000样本、128维、2个真相关特征 |
| 数据种子 | 20261127；Ring 为20261128 |
| 置换 | 分别用种子20261227、20261228打乱列位置，保存置换与真值 |
| 划分 | StratifiedKFold，6折，shuffle=True，random_state=20261127 |
| 配对 | 每折三种 scaling 使用相同训练数据、初始权重与随机训练序列 |
| 训练 | CPU、2线程、120 epoch，其中40 epoch warmup；不是原500/120预算 |
| 优化器 | Adam，lr=0.005，weight_decay=0.001；进入 ADMM 时按旧路径重置优化器 |
| 稀疏更新 | C=0.05、初始ρ=50，保留残差平衡及对偶重缩放；λ_j=C/scaling，截到[1e-8,0.5] |
| 随机正则 | feature dropout=0.6，网络 dropout=0.04308691548552568 |
| score | 128条训练行，每10个 ADMM epoch 刷新，计算 batch size=32 |
| 读出 | 主表统一使用最终原始 gate 的绝对值，其他两个 score 读出仅作诊断 |
| 参数与 checkpoint | 无超参数搜索，无基于真值或测试损失选择 checkpoint，使用最后一轮 |

环境为本机已有 Python 3.13、PyTorch 2.11.0+cu130、NumPy 2.3.5、scikit-learn 1.7.2。本轮实际 device 为 CPU，没有 GPU 训练或下游选列重训。

## 结果

以下为6折均值，主读出固定为 |gate|。这6折共享同一份任务数据，不是6份独立生成实例。各折完整分数、指标与耗时见 [逐折结果](<20261127 候选一 Ranking 证据/results.jsonl>)，诊断读出见 [汇总](<20261127 候选一 Ranking 证据/summary.json>)。

| 任务 | scaling 来源 | recall@2 | 排名 AP | 恢复 AUROC |
| --- | --- | ---: | ---: | ---: |
| XOR | 第一层列范数参照 | 1.0000 | 1.0000 | 1.0000 |
| XOR | 一阶 | 1.0000 | 1.0000 | 1.0000 |
| XOR | 一阶＋经验 Fisher 二阶 | 1.0000 | 1.0000 | 1.0000 |
| Ring | 第一层列范数参照 | 0.0833 | 0.1701 | 0.7526 |
| Ring | 一阶 | 0.0000 | 0.1470 | 0.7308 |
| Ring | 一阶＋经验 Fisher 二阶 | 0.0833 | 0.1993 | 0.6964 |

Ring 的二阶方案只在一折 Top-2 中命中一个相关特征，其余五折均未命中。AP 高于另两种，但 AUROC 更低，不支持把单个指标改善写成排名全面改善。XOR 的主指标已经饱和，无法用本表判断哪种 score 更优。

未执行混合任务、完整维度网格、独立数据种子、原500轮预算、外部 baseline 重跑或下游任务。下一步优先检查 Ring 中任务拟合与 score/阈值饱和情况，再决定完整预算与多实例确认，不能按本轮真值反复选择更有利的绝对值规则或配置。
