# Deep Regularization 会议纪要：恢复有效基准、无 gate score 与旋转量化

> 会议日期：2026-09-06。状态：diagnostic / 会议内容整理。本文依据完整录屏的两遍本地自动语音识别与共享画面核对，采用主题化转述，不是逐字人工听录。会议方向、口头结果、整理者的数学说明分别标明；不据此修改当前算法或授权实验。

## 核心结论

本次会议的主线是：**先明确旧版本为什么能 work，并在当前算法下找回接近旧版本的 Ring 表现，再判断能否用权重侧的动态 score 去掉独立 gate。** 现有 A/D 对照说明了一种有效 gate 与直接权重列参数化的差异，但 D 使用列范数，并没有直接检验会上要求的“梯度乘权重、逐元素计算、按输入特征聚合、参与训练”的方案。

指导方反复要求补上两件基础工作：**一份能逐步核对的新旧算法伪代码；在固定算法条件下比较 score 的消融。** 优化算法、score、调度、读出究竟改了哪些，会上仍未解释清楚，因此没有把 Ring 的退化认定为某个单独因素造成。

量化是第二条探索线，优先级低于先理清 gate 问题。建议从正常训练的小型 MLP 开始，加入保持全精度功能的 rotation，再学习旋转并考察量化；讨论中明确将“rotation + pruning”纠正为“rotation + quantization”。这仍是探索建议，未冻结实验细节。

## 三处关键技术讨论

### 1. “梯度乘以 gate”需要区分讨论对象

你的笔记抓住了“乘梯度、element-wise、再 sum over”的骨架，但在 **08:15–10:50 的无 gate 讨论**中，乘子的对象明确转到权重 W，不能继续只写 gate。画面上的矩阵和乘积见 [09:00](./20260906_media/frame_0900.png) 与 [11:00](./20260906_media/frame_1100.png)。

为避免与仓库里有效 gate 的命名冲突，这里用 P 表示要评分的第一层权重：无 gate 模型中 P 就是直接训练的权重；吸收独立 gate 后，P 是合并后的有效矩阵。对输入特征 j，先计算

```text
dᵢⱼ = ∂L / ∂Pᵢⱼ                 当前监督损失的梯度
tᵢⱼ = Pᵢⱼ · dᵢⱼ                 每个权重位置上的一阶乘积
Sⱼ  = 沿输出维 i 聚合 tᵢⱼ        每个原始输入特征一个 score
```

**会议转述：** 08:52–09:20 提到逐元素平方后求和，09:29–09:45 提到不必开根号、把内部项换成梯度乘 W；11:00 左右画面也标注乘积及平方。因此 `Sⱼ = Σᵢ tᵢⱼ²` 是有音画依据的候选理解。不过 10:16–10:49 又以“删一整列的一阶 loss 相加”解释它，会上没有正式处理这两种写法的区别。纪要不将候选写成最终冻结公式。

**整理者的数学说明：** 删除整列时，参数变化为 `ΔPᵢⱼ = −Pᵢⱼ`。直接代入一阶展开，得到 `ΔLⱼ ≈ −Σᵢ tᵢⱼ`。因此下列量一般不同：

| 量 | 含义 |
|---|---|
| `−Σᵢ tᵢⱼ` | 有符号的一阶整列删除估计 |
| `|Σᵢ tᵢⱼ|` 或 `(Σᵢ tᵢⱼ)²` | 先聚合，再衡量整体变化大小；允许列内正负抵消 |
| `Σᵢ |tᵢⱼ|` 或 `Σᵢ tᵢⱼ²` | 先衡量各元素大小再聚合；不发生同样的正负抵消 |

这正是 pseudocode 需要固定的地方：平方/绝对值在求和之前还是之后，求和轴是什么，梯度来自监督损失还是包含增广项的训练损失，是否使用历史平滑。会上没有给这些项完整定案。

会上将一阶乘积口头放在 OBD 语境下；整理时更准确地称为 **一阶 Taylor saliency 候选**，不把它直接等同于经典二阶 OBD。使用一阶信息近似剪枝损失变化有明确的原始文献来源，见 [Molchanov 等的 Taylor pruning 论文](https://arxiv.org/abs/1611.06440)。该文献不替本次会议确定列聚合方式。

### 2. Weight norm、gate 吸收与 ADMM track score 是三个层次

**19–21 分钟的画面核对：** 指导方把 gate 乘权重范数与合并后的权重范数放在一起讨论，见 [21:00 批注](./20260906_media/frame_2100.png)。对于真正线性相乘的一列，若原始标量因子为 sⱼ、权重列为 wⱼ，则

```text
qⱼ = sⱼ · wⱼ
‖qⱼ‖₂ = |sⱼ| · ‖wⱼ‖₂
‖qⱼ‖₂² = sⱼ² · Σᵢ wᵢⱼ²
```

**整理者说明：** 这说明同一有效列的幅值可以在吸收前后等价表达，不能证明旧代码中的任何 raw weight norm 都可直接乘回当前模型。尤其原始范数若已在前向中被归一化抵消，就要重新核查它在 score、前向、正则和训练反馈中的位置。只在最后排序时，非负分数取平方根不改变排序；把不同幂次的 score 放入正则器或约束，则不能因此宣称算法等价。

会上把额外权重范数解释为补充权重侧信息，这是设计动机的口头回顾。它也不能推出 gate 梯度与权重无关：当监督损失经由 `qⱼ=sⱼwⱼ` 依赖这两者时，链式法则给出 `sⱼ · ∂L/∂sⱼ = Σᵢ qᵢⱼ · ∂L/∂qᵢⱼ`。这条有符号恒等式仍不等于“逐元素平方后相加”，也不使所有历史 score 自动等价。

**23:00–23:45 的会议方向：** 指导方希望 ADMM 一直处理每个输入特征的 score，阈值操作也作用于 score，以免跟踪整个第一层矩阵；不管 score 最初来自 gate、权重还是梯度，都要明确处理对象。这里讨论的是让 score 影响训练的主动机制，不是仅在训练结束后换一个 Top-k 排序。

**未解决的实现问题：** 动态 score 若依赖当前梯度，必须明确什么是优化变量、什么是观测量；是否停止梯度；若继续对梯度 score 求导是否出现高阶导数；ADMM 的静态目标、约束、z/u 更新顺序是什么；score 被压缩后怎样反馈到网络参数。会上没有给出这些定义，也没有推导出 RatioNorm 对应的具体近端更新。口头“soft thresholding”不能替代该子问题的正式解。

### 3. Rotation 实验的完整含义

**会议建议（26:55–29:15）：**

1. 正常训练一个简单 MLP，建立全精度参照。
2. 加入 rotation；首先确认变换本身没有破坏模型原来的功能。
3. 再加入能维护正交约束的 SGD 来训练旋转。口述疑似提到 Cayley SGD，具体变体需实现前核实。
4. 在这种表示调整下研究量化。会中明确纠正了“与 pruning 结合”的说法；暂不从大型模型开始。
5. 讨论允许在不改变全精度输出的条件下，用额外目标训练 rotation 或 scaling；sparsity objective 被提及为候选，但没有确定最大化/最小化方向、作用张量和最终损失。

**整理者说明：** “quantization 需要相近数字”可更精确地理解为：固定 bit 数和量化范围时，极端离群值会拉大量化步长，影响主体数值的表示精度；优化动态范围与离群值可能有利。它不等于要求所有值相同，也不存在单靠零值比例就能断言量化好坏的结论。输出不变要依赖合适的成对变换与吸收位置，不能仅凭旋转矩阵正交就跨任意非线性移动它。

会议中“过去的 rotation 通常不训练”等话属于口头概括，不作为新颖性结论。公开的 [SpinQuant 原始论文](https://arxiv.org/abs/2405.16406) 已明确讨论学习旋转、全精度等价与量化精度；本次 MLP 建议首先应理解为机制学习和小规模验证，不能据会议直接宣称新方法。
