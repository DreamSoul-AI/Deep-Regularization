# GRN-FS-Five-v1：五项候选研究版本

登记日期：2026-09-13。用户决定：“先把五项候选的作为一个版本吧”。

本版本固定现有 **M31 = R+W+H+U+D** 配方，作为后续研究可引用、可比较的版本。
其 Ring 与混合任务的 Top-k 改善值得保留。版本身份为 `candidate`；主方法默认不变，
R58 原不退化判定仍为失败，尚未证明最小性。本次只登记现有实现与证据，没有新训练。

## 固定的五项改动

| 项 | 精确含义 |
|---|---|
| R：局部平方 | 每个原始变量的线性/平方通道共享一个父特征 gate；无交叉乘积项。平方权重从零初始化，从第一个 warm-up backward 起允许学习。 |
| W：旧版初始化规则 | 第一层线性权重恢复同 seed 的默认 Kaiming-uniform 抽样，使用当前输入维数；原始 gate 因子为 1，平方权重仍为零。不是旧版全多项式网络的逐位复现。 |
| H：隐藏层 dropout | 第一处 Mish 之后加入 dropout，概率固定 0.043；不是输入 dropout。 |
| U：平方仅中心化 | 保留训练折平方均值中心化，撤去平方标准差缩放；原始输入仍按训练折标准化。 |
| D：Adam weight decay | 耦合 Adam L2，非 gate 参数（包括 bias）为 0.001，gate 为 0；不是 AdamW。该项改变诊断优化目标，不能直接继承零 WD 的目标等价性结论。 |

固定 20 轮监督 warm-up + 100 轮 ADMM；两个 32 宽 Mish 隐藏层；Adam lr=0.005、batch=64、rho=50。
五个 C 阶段各 20 轮，倍率依次 1/256、1/64、1/16、1/4、1；本版保留已验证终点 C=12.8。
warm-up 结束后新建 ADMM Adam、z=g、u=0，随后五阶段保持网络、Adam 与 z/u 连续。
数值 prox 使用既有 `isolated_v1`。训练和评估采用确定性 cuda:0，无 CPU fallback、AMP 或 TF32。

主读出是最终有效 gate 绝对值的非零 Top-k，并列按原始索引升序，zero tolerance=0。
已验证任务的 k 分别为 2、2、4、6；k 用于读出，不在训练中截断输入。
20 轮 warm-up、立即开放平方是本版本定义；R59 的 40 轮或延迟开放组不并入 v1。

## 文件与复用入口

- [preset.json](preset.json)：与 R58 M31 完全一致的八字段配方，可由未来实验读取。
- [version.json](version.json)：版本身份、有效训练设置、精确源码/依赖/证据/已有 checkpoint SHA-256。
- [version.py](version.py)：仅使用 Python 标准库的只读加载与完整性检查；不会导入训练器或启动实验。
- [verification.json](verification.json)：本次登记的完整性核验记录。

从迁移研究目录 `research/legacy-migration/NEW_Pruning_20251110` 执行：

```powershell
C:/Python310/python.exe -X utf8 versions/grn_fs_five_v1/version.py
```

在未来已登记的实验代码中读取固定配方：

```python
from versions.grn_fs_five_v1.version import load_preset

arm = load_preset()  # 校验版本与锁定文件，返回独立的配置字典；不训练。
```

实际训练入口仍为已有的
[`legacy_wd_family_r58.train_arm`](../../experiments/ablation/legacy_wd_family_r58.py)，
其初始化、训练、平方变换及读出应整体复用。新实验另设数据、seed、输出目录与预算，
不重启已关闭的 R58 控制器。`version.json` 的有效训练设置剔除了旧 checkpoint config
中继承但不控制本轮实验的任务名、seed、轨迹数和 refit 字段；数据身份以各轮合同和逐条结果为准。

版本通过相对路径锁定本仓库保留文件，不是可脱离仓库运行的发布包；原训练加载器仍有
历史绝对路径依赖，迁移时需按原复用检查处理。现有 checkpoint 保留在原结果目录，
不复制、不替换。以后改变五项配方或固定训练设置，应登记新版本，保留本版结果及失败记录。
