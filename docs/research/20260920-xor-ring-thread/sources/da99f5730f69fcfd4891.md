# 会议汇报：9 月 6 日讨论后的进展

汇报截至 2026 年 9 月 18 日。本文承接 [9 月 6 日会议纪要][meeting0906]及[当时的汇报材料][report0906]，从上次留下的问题讲起。实验编号、全部维度数值和逐轮配置另见[技术附录][technical]。

## 一、上次会议要求先解决什么

上次会议的主要问题是：**以前有 gate 的方法在 Ring 上能选对特征，为什么整理后的当前方法反而做不好？先把这个有效参照找回来，再讨论能否去掉独立 gate。**

**已有基础：** 0906 汇报已经解释了有效 gate、权重与特征评分的关系，给出了吸收 gate 的等价推导，并汇报了有／无 gate 对照以及终点、训练历史中的评分检查。本次沿用这些结论，重点报告此后恢复 Ring 和扩展维度的实验。[上次已完成的分析与实验][report0906]

具体有三项相互衔接的工作。

1. **说清新旧算法到底差在哪里。** 并排列出前向计算、score、ADMM 更新、训练调度和最后怎样选特征，不能把多项差异都概括成“换了 score”。
2. **先建立有效的有 gate 参照。** 找到旧成功结果对应的实现，检查恢复过程；在固定其他条件时比较 score，解释 Ring 的差距。
3. **再探索无 gate 的主动 score。** 老师提出从“权重 × 对应梯度”出发，按输入特征聚合，并让 score 参与训练和阈值反馈。它不同于只在训练后换一个排序，也不同于已有的权重列范数对照。

此外，会议还提出了小型 MLP 的 rotation + quantization 探索，优先级低于先理清 gate。上述内容是对会议的转述，会议并未冻结完整的新算法。[会议要求与时间定位][meeting0906]

**这次的进展主要在前两项的基础工作：重现并分析了一条旧 Ring 成功路径，随后在当前方法上找到了明显改善 Ring 的候选配置。但我们还没有恢复一套同时兼顾 XOR、Ring 的可靠方案，也没有完成老师提出的无 gate 主动 score 算法。**

## 二、Legacy、Base 与五项候选的算法对照

后文把上次汇报中的原始输入、有效 gate 方法称为**当前基线**，图中的英文标签是 `Base`。它是本阶段所有改动的起点。

这里用于解释旧 Ring 成功的**旧多项式版本**，则同时包含线性项、平方项和两两乘积项，训练及读出规则也不同。两者不只是最后换一个分数。

下面按实际执行顺序并列三个方法：旧 Ring **完整配置**、当前基线 **Base**，以及在 Base 上加入局部平方、默认权重初始化、隐藏层 dropout、平方仅中心化和 weight decay 的**五项候选（Five-v1）**。固定配置见[版本说明][five-version]。本文把这一旧全多项式配置记为 **Legacy-poly2**；结果表与算法表使用同一“无 warm-up”配置。**WN-legacy** 是另外一条仅使用原始输入的历史分支，用于补充高维参照，不能替代 Legacy-poly2。

**共同设置：** 两层宽度 32 的 Mish 网络；Adam 学习率 0.005，batch=64；原始 gate 初值为 1。下表省略梯度清零、反向传播等常规操作，**差异加粗，相同流程只写“同 Base”或“同旧版”**。

**有效 gate = 原始 gate × 对应第一层权重的长度。** Base 使用单个线性通道的权重；五项版将同一特征的线性、平方通道权重一起计算长度。“同 Base”指该行操作相同，输入和训练配置仍按各列取值。

| 执行步骤 | 旧 Ring 全多项式版（Legacy-poly2） | 当前有效 gate 基线（Base） | 我们的五项候选（Five-v1） |
|---|---|---|---|
| 1．模型输入 | 原始输入 → **线性、平方、交叉项**；每个展开项独立 gate。平方和交叉项直接使用。 | 原始输入 → **每个特征一个 gate**。 | 原始输入 → **线性＋平方，共享 gate**；无交叉项。每列平方项减去自身的训练折均值，不除标准差。 |
| 2a．第一层初始化 | 线性、平方、交叉项权重 → **全部默认初始化**。 | 默认初始化 → **每列权重归一到长度 1**。 | **线性默认初始化，平方为 0**；平方权重从第一轮开始学习。 |
| 2b．dropout | 第一层前、第一处 Mish 后 → **各使用 0.043 dropout**。 | **不使用**。 | 第一处 Mish 后 → **使用 0.043 dropout**。 |
| 2c．weight decay | **非 gate 参数为 0.001**，包括 bias；gate 为 0。 | **全部为 0**。 | 同旧版 |
| 3a．每次前向 | 同 Base | 输入按原始 gate 缩放 → 两层 Mish 网络 → 输出；dropout 按上面的配置执行。 | 同 Base |
| 3b．ADMM 跟踪对象 | **原始 gate**。 | **有效 gate**；约束梯度同时传到 gate 和第一层权重。 | 同 Base |
| 4．warm-up | **无**，直接进入 ADMM。 | 监督训练 **20 轮** → 新建 Adam → 辅助变量设为当前有效 gate，对偶状态清零。 | 同 Base |
| 5．训练阶段 | 稀疏强度依次 **0.1 → 0.2 → 0.5 → 1 → 2**；每阶段 **50 轮**，ADMM 惩罚系数 **200**。 | 稀疏强度依次 **0.05 → 0.2 → 0.8 → 3.2 → 12.8**；每阶段 **20 轮**，ADMM 惩罚系数 **50**。 | 同 Base |
| 6．阶段入口 | 保留网络 → **重置 Adam；辅助变量复制当前原始 gate，对偶状态清零**。 | **保留网络、Adam 动量及 ADMM 状态**。 | 同 Base |
| 7．每轮阈值调节量 | 每轮开始，将每个展开项连接到第一层的权重平方求和、开根号 → **缓存权重范数，用于调节本轮收缩阈值**。 | **无需该额外调节量**。 | 同 Base |
| 8．每轮网络更新 | 同 Base | 固定辅助变量和对偶状态 → 用分类损失＋ADMM 增广项更新网络。 | 同 Base |
| 9．每轮稀疏更新 | 当前原始 gate＋对偶状态 → **按缓存的权重范数调节各坐标阈值，做软阈值收缩** → 乘旧版三次方程给出的统一缩放系数 → 更新辅助变量。 | 当前有效 gate＋对偶状态 → **用统一稀疏强度做 RatioNorm 近端更新** → 更新辅助变量。 | 同 Base |
| 10．每轮对偶更新 | 同 Base | 对偶状态累加“当前跟踪量－辅助变量” → 继续下一轮或阶段。 | 同 Base |
| 11．最终选特征 | 原始 gate 取绝对值 → **聚合回原始特征**（线性、平方项全归父特征，交叉项各分一半）→ Top-k。 | **最终有效 gate 取绝对值 → Top-k**。 | 同 Base |
| 总训练量 | **250 轮**。 | **120 轮**。 | 同 Base |

dropout 和 weight decay 在各训练阶段均生效；训练中不把辅助变量直接写回 gate，也不在阶段间剪枝。旧版的软阈值加整体缩放是历史近似更新，与当前 RatioNorm 近端更新不同。

**这里区分三个用途：** 旧代码把阈值调节用的权重范数命名为 `score`；旧 ADMM 跟踪的对象仍是原始 gate；最终 Top-k 使用原始 gate 幅值的父特征聚合。会议提出的“ADMM 跟踪 score”则希望特征评分本身成为约束与稀疏更新的对象，不能与旧代码的变量名混同。[会议讨论][meeting0906]、[旧更新实现][gate-source]

读出细节：Base 和五项版并列时按特征索引排序；非零分数不足 k 个时，只返回非零项并记录数量不足，不用零分项补齐。非零项足够时，与相同并列规则的普通 Top-k 一致。[读出实现][topk-source]

**五项版是在 Base 上借鉴部分旧设置形成的组合。** 局部平方、平方权重从零开始、只保留隐藏层 dropout，都与旧完整展开版本有区别；默认初始化的尺度也随输入维数变化。

**表外数据处理：** 旧版先用全数据标准化，再划分训练和测试；Base 与五项版先划分，只用训练折计算标准化统计量。旧版展开后直接使用平方及交叉项；五项版另外减去每列平方项的训练折均值。

配置来源：[旧 Ring][legacy-config]、[Base][base-config]、[五项版][five-version]。实现核对：[旧运行入口][legacy-runner]、[旧更新][gate-source]、[当前训练流程][base-runner]、[当前模型][base-source]、[当前近端算子][base-prox]。Legacy-poly2 的四任务历史结果取自 [warmup0 分支][poly-data]，配置含义见[历史诊断脚本][poly-runner]；单折 GPU 过程核查另见[旧路径核查][legacy-ring]；上次方法背景见[9 月 6 日汇报][report0906]。

五项版的逐项探索、子集检查及保留依据见[形成过程与实验日志][minimal-log]；会上正文直接比较结果。

## 三、现在恢复了多少效果

评价重点是 **Top-k 找回多少真实特征**。XOR 和 Ring 各有两个真实特征；下面常用的分母 24 来自“两份数据实例 × 每份六折 × 每折两个真实特征”。混合任务分别有四个、六个真实特征，因此分母为 48、72。折之间共享数据，不是独立数据实例。

### 1. 128 维：旧 Ring 全多项式版、Base 与五项候选

Base 与五项候选是同一轮、同数据与划分的配对结果。旧版列采用与算法对照一致的 **Legacy-poly2（无 warm-up）** 四任务历史记录。各格为选中真实特征数 / 真实特征总数。

| 任务 | 旧 Ring 全多项式版 | 当前基线 Base | 五项候选 Five-v1 |
|---|---:|---:|---:|
| XOR | 12/12 | 23/24 | 22/24 |
| Ring | 10/12 | 0/24 | 23/24 |
| Ring+XOR | 12/24 | 13/48 | 27/48 |
| Ring+XOR+Sum | 24/36 | 21/72 | 44/72 |

**旧 Ring 全多项式版可以用于比较。** 这里使用已保存的六折终点，而非把单折 GPU 重现当成六折结果。四任务命中率分别为 100.00%、83.33%、50.00%、66.67%。它来自一个实例六折，Base/Five 来自两个实例各六折，且预处理和训练协议不同，因此只有 Base/Five 是配对比较；旧版按历史参照展示。[四任务逐折原始结果][poly-data]

### 3. 扩展维度后：Ring 保留较多收益，XOR 很快失效

固定五项配方后，补齐了四个任务共 42 个任务—维度组合。下表是 XOR/Ring 的关键点，全部维度见图和技术附录。

| 维度 p | 五项候选 XOR | 五项候选 Ring |
|---:|---:|---:|
| 64 | 24/24 | 24/24 |
| 128 | 22/24 | 24/24 |
| 256 | 2/24 | 18/24 |
| 512 | 1/24 | 18/24 |
| 1024 | 0/24 | 20/24 |
| 2048 | 0/24 | 15/24 |

![固定五项候选的完整维度曲线，以及当前基线已有的测量点](meeting_20260918/dimension_recovery.png)

图中蓝线是刚介绍的五项候选，灰色方点是当前基线在这组配对迁移数据上已有的测量点。当前基线在 512/2048 维的 XOR 也分别为 0/24、0/24，所以高维 XOR 的弱点并不是五项候选才出现的。不同维度的实例不嵌套，曲线的局部起伏不能直接解释为维度变化的因果效应。[全维度数据][r62-data]

在 512/2048 维、四个合成任务等权的宏平均 recall 上，基线为 **6.16%**，五项候选为 **37.33%**。这说明固定配方在所测高维合成任务上有整体收益，但不能掩盖 XOR 接近失效。[配对迁移结果][r61-data]

**DAG 上没有得到同样的收益。** 主指标 Top7 的真实特征命中为 7/42→7/42，Top81 为 49/486→43/486。现在不能声称方法在一般高维数据或 DAG 上都更好，也不能称为因果特征恢复。[DAG 结果][r61-report]

## 四、高维 XOR 为什么选不对：目前查到了什么

### 1. 先检查模型有没有用到真实特征

Top2 没选对有两种可能：模型用到了真实特征，但 gate 排名没有把它们排在最前；或者模型本身就没有明显使用真实特征。为区分两者，我们固定训练好的模型，打乱某些特征的样本顺序，再观察预测变化。

| 已有观察 | 能说明什么 |
|---|---|
| 部分 256 维失败折：Top2 只选中一个真特征，但分别打乱两个真特征都会明显破坏预测 | 模型已经用到两个真特征，最终 gate 排名却没有完整反映这种依赖 |
| 所查的 512 维轨迹：打乱真特征对几乎不改变输出，打乱高分噪声对却影响明显 | 这些模型没有明显利用真实特征，仅调整最后的排序不足以解释全部失败 |
| 初始 warm-up 结束时，打乱噪声的样本对应关系已经会明显破坏训练预测 | 对噪声的依赖在进入 ADMM 前就已出现，不能把全部问题归因于后续稀疏更新 |

因此，目前定位到的是**“模型如何学到真实依赖”与“gate 如何反映这种依赖”两个环节都有问题**。这些检查尚未确定是平方通道、dropout、weight decay 或某个优化步骤造成的。[扰动实验与逐折结果][r65-report]

### 2. 围绕训练过程做了哪些尝试

历史 WN-legacy 的 XOR 在 256/512 维曾达到 12/12、10/12，提供了检查旧训练设置的线索；它的 Ring 同时只有 1/12、0/12，不能直接作为兼顾两任务的方案。后续仍从五项版出发，分别检查下面几类改动。[旧记录][legacy-data]、[实现差异][r66-report]

| 尝试 | 具体改动 | 结果 |
|---|---|---|
| 多训练一段时间 | 在现有最后一个 C 上继续训练，累计到 1200 轮 | 所查 512 维 XOR 仍未恢复 |
| 降低学习率、放慢 C 的推进 | 学习率改为 0.001，每个 C 训练 100 轮 | Ring512 从 18→23/24；但 Ring256 为 18→17/24，XOR512 为 1→0/24 |
| 借鉴旧 C 路径 | 替换全局 C 序列，再检查延长阶段 | 未得到两个高维 XOR 都改善的方案 |
| 重置阶段状态 | 每阶段重置 Adam；再检查同时重置 ADMM 状态 | 部分 Ring512 结果改善，高维 XOR 未恢复 |
| 每阶段增加 warm-up | 第 2—5 阶段前各加 20 轮普通监督训练 | XOR256 2→2/24，XOR512 1→0/24；Ring512 18→21/24 |

上述各行是不同实验，不是依次叠加的改动。第一行使用内层训练划分，其余使用完整外层训练折；具体配置及全部结果见[技术附录][technical]和[训练延长][r64-report]、[慢路径][r67-report]、[C 路径][r68-report]、[阶段重置][r69-report]、[逐阶段 warm-up][r70-report]。

**目前的结果是：这些改动能在部分条件下继续提高 Ring，但尚未找到让高维 XOR 明显提高、同时保住 Ring 的改动。** 慢路径因 Ring512 的收益单独保留为[候选版本][slow-version]。逐阶段记录也没有显示统一的“warm-up 已经选对、随后被 ADMM 破坏”的过程，具体排名变化保留在附录。

## 五、本次结论与还没解决的问题

**第一，Ring 已有实质改善。** 五项版在当前 Base 上恢复了较好的 Ring 特征选择，并在所测高维 Ring 和混合任务中保留较多收益。这是本轮最明确的进展。

**第二，同时做好 XOR 与 Ring 的目标还没完成。** 128 维的原不退化检查仍有 XOR 退化，高维 XOR 更明显失效；DAG 也没有表现出一致改善。现在保留五项版作为继续研究的起点，尚不能把它称为最小不退化方案。

**第三，score 与 gate 的已有分析沿用 0906 汇报。** 上次已经说明 gate 怎样与第一层权重合并、有效 gate 与列范数评分的关系，以及相同预测函数和静态目标为什么仍可能产生不同训练路径；也已经做过有／无 gate 的 A/D 对照，以及梯度、曲率和历史评分检查。已有结果没有建立独立 gate 的稳定优势，所查替代评分也未修复当时的 Ring 特征恢复。这些是已完成的推导和实验，不应重新列为“尚未回答”。[0906 汇报中的具体结论][report0906]

尚未完成的后续方向更具体：**把梯度等动态评分直接用于训练反馈，形成新算法并与已有方法比较。** 这与上次已完成的列范数无 gate 对照、训练后评分及被动历史记录不同。本轮主要新增五项配置及其维度扩展结果，没有追加这类主动评分算法的验证。[会议后续方向][meeting0906]

当前按讨论暂停新增实验。后续仍需找到在保住 Ring 的同时改善高维 XOR 的方案；这里不重讲上次的 score / gate 推导，也不把旧结论列作本轮新增结果。
