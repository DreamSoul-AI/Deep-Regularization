# 旧版 Ring 为什么能反超：GPU 重现与贡献拆解

日期：2026-09-07。范围：旧版 full-poly2 Ring，fold 0 / seed 1051；不是当前有效 gate 方法的新 benchmark。按[冻结合同](../plans/PLAN_20260906_LEGACY_RING_TRANSITION_OBSERVATION_V1.md)完成两条件、四条 GPU 训练，共 1000 epoch，没有重跑任何已完成轨迹。

**结论：这条旧成功路径并不是“真实 gate 一直变大”。关键窗口中，真实平方项的权重尺度变大，有效幅值增强；与此同时，噪声相关项大量减弱，原始 gate 聚合排名随后反超。**

运行状态为 `partial_observation_failed`，不是全部检查通过：score 配对通过历史、逐状态和数值重放检查，可做下述轨迹分解；uniform 的参考终点重现历史，但详细记录副本因初始化 CUDA RNG 字段差异未通过严格边界检查，原地隔离，不用于机制归因。两次核对中断与具体原因见附录 C。没有放宽容差或豁免失败条件。

## 1. 首先，旧结果确实重现了

两个参考运行均通过各自的五阶段历史行为核对：Top-2 集合、真实排名及 z 支持数全部一致，终点 train/test AUROC 也满足原定误差要求。本次不是历史参数逐位重现证明，因为历史完整权重没有保存。

| 参考运行 | 第 50 / 100 / 150 / 200 / 250 轮父特征 recall@2 | 最终选中 | 测试 AUROC |
|---|---|---|---|
| 保留旧 score | 0 / 0 / 0 / 1 / 1 | {0,1} | 0.997131 |
| 移除旧 score | 0 / 0 / 0 / 0 / 0 | {37,69} | 0.462708 |

这重现了旧配对的终点差异，但不单独识别 score 的整体压力、相对加权或动态更新各自的作用。[参考结果与检查](../../results/ablation/legacy_ring_transition_v1_20260907_103753/closure_audit.json)

## 2. 反超来自“下降得更少”，还是“真正变强”？

两者发生在不同坐标，不能混称为 gate 变大。这里 $s$ 是旧代码存储的 gate，$a$ 是第一层权重列范数，$g=a\odot s$ 是有效幅值。旧方法主读出聚合 $|s|$，$|g|$ 聚合只作诊断。

父特征分数沿用旧规则：线性项与平方项全归各自父特征，交叉项各分一半。取较弱真实父特征的分数 $T$，以及每轮最强噪声父特征的分数 $N$；$T>N$ 才表示两个真实特征都严格领先。

| 第 150→200 轮 | 真实瓶颈 $T$ | 最强噪声 $N$ | 差距 $T-N$ |
|---|---|---|---|
| 原始 gate 聚合（主读出） | 1.194510 → 0.509559 | 1.992445 → 0.327062 | −0.797935 → +0.182497 |
| 有效幅值聚合（诊断） | 0.481350 → 1.059486 | 0.639906 → 0.117708 | −0.158555 → +0.941778 |

原始 gate 聚合的差距改善为 $-0.684950+1.665383=0.980432$：真实分数也降了，只是噪声降得更多。有效幅值的差距改善则为 $0.578135+0.522198=1.100333$：真实增强与噪声下降共同发生。这里是精确数值记账，不是两个独立干预的因果效应。[固定窗口分解](data/legacy_ring_transition_contributions_validated_score_20260907.json)

从完整轨迹看，有效幅值聚合从第 **157** 轮起一直保持严格优势；原始 gate 聚合第 166 轮短暂领先，167–169 轮失去优势，第 **170** 轮起保持到终点。没有按这些时刻改变训练、选 checkpoint 或提前停止。

## 3. 真正增强的具体是什么？

主要可定位到两个真实平方项；不是两个原始线性项，也不是 $x_0x_1$ 交叉项。

下表各列均为第 150→200 轮的数值：

| 项 | gate 幅值 $\lvert s\rvert$ | 权重尺度 $a$ | 有效幅值 $\lvert g\rvert$ |
|---|---|---|---|
| $x_0^2$ | 0.397278 → 0.385484 | 0.810938 → 2.692973 | 0.322168 → 1.038099 |
| $x_1^2$ | 0.615435 → 0.614989 | 0.534714 → 2.071217 | 0.329082 → 1.273775 |

两个平方项的 gate 都没有在这个窗口净增长；它们的有效幅值增长来自权重尺度的增长。逐 minibatch 记录也显示，700 次更新中两列范数分别有 649 次、566 次增大。这是实际参数变化，不只是梯度方向猜测。

文中的“有效增强”指第一层有效幅值这一观测量，不等同于已经测得删除损失或因果重要性增加。

到第 250 轮，平方项分别占两个真实父特征有效幅值聚合的 **99.33% 和 99.92%**；z 的两个精确非零位置恰为 $x_0^2,x_1^2$（展开索引 128、256）。但原始 gate 仍有 8384 个精确非零值，不能把这说成 z 已写回、其它 gate 已硬置零。

因此，本条成功轨迹使用了平方表示；**不等于已经证明平方项必要、充分，或者 full-poly2 比仅加平方更好**。这些需要改变表示的匹配干预，不能从一个成功终点推出。

## 4. 哪些噪声贡献下降，为什么真实分数也会下降？

关键窗口中，真实父特征 0 的原始聚合损失了 0.670435 的“真实×噪声”交叉项贡献。它虽然是真实父特征，但原分数里包含大量这种混合项；清除混合项会让它的总分下降，并不表示其平方路径也同等变弱。

与此同时，最强噪声包络的下降中，纯噪声交叉项贡献 1.273250，线性项贡献 0.349693。它们超过真实瓶颈的下降量，最终使主读出反超。有效幅值坐标则是平方项提供 +0.715932 的真实增长，抵消混合项的 −0.139672，得到净增长 +0.578135。完整五类加总见附录 A。

所以，旧 Ring 的可观察过程更适合表述为：

**平方路径得到保留并增强 → 许多混合项与噪声项减弱 → 有效幅值先形成优势 → 原始 gate 的父特征聚合随后也选对。**

这里的箭头概括时间顺序与记录到的更新关系，不代表各环节的独立因果贡献已被识别。

## 5. score 与 ADMM 在这条过程中做了什么？

旧 score 是每轮神经更新前缓存的列范数 $r=a_{\mathrm{pre}}+10^{-8}$。它进入旧收缩阈值

$$
t_j=\frac{\max(C/r_j,10^{-8})}{\rho}.
$$

因此，同一轮 $r_j$ 较大的项面对较小阈值。这是旧更新的实际数值关系，不是把当前方法改回逐坐标 C。

| epoch | 全坐标阈值中位数 | $x_0^2$ 阈值 | $x_1^2$ 阈值 |
|---|---|---|---|
| 150 | 0.057759 | 0.002922 | 0.004778 |
| 200 | 0.377327 | 0.001888 | 0.002429 |
| 250 | 4.865468 | 0.003063 | 0.004894 |

平方项在全部 250 个轮末都保持非零 z，而许多其它项进入零支持。第 150→200 轮 C 从 0.5 变成 1，但平方项的缓存 score 增大得更多，实际阈值反而下降；全坐标阈值中位数则明显上升。

随后，z/u 改变下一轮神经块追踪的目标 $z-u$。它们不直接覆盖 gate。第 200 轮，两个平方项的目标分别为 0.386768、0.617572，略高于对应 gate 0.385484、0.614989；可见加上旧公共 cubic rescale 与对偶反馈后，不能将整个 ADMM 过程简单描述为“永远把每个 gate 往下压”。跨阶段则按历史规则重置 Adam、z/u。

监督梯度、增广梯度和 Adam 更新都已记录；但它们不是三个能直接相加成因果百分比的模块。两个平方项在关键窗口的监督方向累计向外、增广方向累计向内，实际 gate 净变化很小，同时权重尺度明显增大。详细数值与梯度相减精度边界见附录 B。

另一个重要限制：移除 score 同时改变相对阈值与整体压力。第 1 轮，score 条件的阈值中位数约 0.014059；按 uniform 规则，同一 C/rho 给出 0.0005，相差约 28.12 倍。不能把两个参考终点的全部差异都叫作“动态 score 的优势”。

## 6. 现在能回答什么，还不能回答什么？

已经能回答：这条旧成功路径中，**平方项的权重尺度增长与噪声相关项的下降，分别承担了有效幅值增强和原始排名反超的可观察变化**。原始 gate 允许反超，且这次实际发生；但不是依靠真实 gate 全程单调增大。

还不能回答：动态 score 相比静态 score 是否必要、相对加权是否比同量级统一阈值更好、ADMM 重置或 Adam 动量独立贡献多少，以及这些结论能否迁移到当前方法。uniform 的详细机制比较还受到本次严格初始化检查失败的限制。

如继续做因果验证，优先把“整体收缩强度”与“相对加权”分开，再讨论动态更新；表示、阶段重置和优化器也各需独立对照。本次不启动这些新条件，不重跑失败副本，不改变当前数学定义或主读出。

## 附录 A：固定窗口的完整记账

五类互斥且穷尽。以下均为第 150→200 轮；“噪声下降”为旧噪声包络减去新噪声包络，负值表示该部分反而增大。

| 类别 | 原始：真实变化 | 原始：噪声下降 | 有效：真实变化 | 有效：噪声下降 |
|---|---:|---:|---:|---:|
| 线性 | −0.001404 | +0.349693 | +0.001902 | +0.126364 |
| 平方 | −0.011794 | +0.003646 | +0.715932 | +0.000680 |
| 真实×真实 | −0.001319 | 0 | −0.000027 | 0 |
| 真实×噪声 | −0.670435 | +0.038794 | −0.139672 | +0.016593 |
| 噪声×噪声 | 0 | +1.273250 | 0 | +0.378561 |
| 合计 | −0.684950 | +1.665383 | +0.578135 | +0.522198 |

真实瓶颈在此窗口始终为父特征 0；最强噪声身份从 31 换成 63（原始）或 69（有效）。上表不能解读为同一噪声特征的下降。固定起点竞争者 31 后，原始差距增加 1.186958，身份切换修正为 −0.206525；有效差距增加 1.194684，修正为 −0.094351。JSON 保存所有 128 个父特征逐轮分数，图中也单列固定噪声 31。

归一化并不改变每轮排名，但改变绝对量的解释。将每轮分数除以当轮总和后，关键窗口原始真实份额为 0.008613→0.024604，最强噪声份额为 0.014366→0.015792；有效真实份额为 0.012688→0.170318，最强噪声份额为 0.016868→0.018922。因此，“噪声下降”在该窗口指绝对包络下降，**不是最强噪声在总量中的占比也下降**。

前一窗口 100→150，原始分数差距由 −3.876111 缩小到 −0.797935，但归一化差距由 −0.000738 变为 −0.005753；这时尚不能说已形成更强的相对优势。后一窗口 200→250，原始真实瓶颈增加 0.041827、噪声下降 0.236059；有效真实瓶颈增加 0.519870、噪声下降 0.098699，优势保持。初始化原始分数全为 65.5，是并列，不是已学会。

进一步将有效幅值变化作对称乘积分解：

$$
\Delta(a|s|)=\frac{a_0+a_1}{2}\Delta|s|+
\frac{|s_0|+|s_1|}{2}\Delta a.
$$

在固定父特征 0 与噪声 31 的比较中，gate 部分为 +0.376923，尺度部分为 +0.817761，合计 +1.194684。平方类别的对应部分为 −0.020318 与 +0.736928。这个对称约定平分乘积交互项，只是精确记账，不等于“冻结另一部分”的实验效果；也不应转成普适因果百分比。

## 附录 B：神经块、梯度与 ADMM 的证据边界

第 151–200 轮共 700 个 minibatch。原始 gate 梯度由总梯度减解析增广梯度重建；记录器对可能被相减误差吞没的监督分量标记不可靠，以下监督和只包含可靠位置。符号按增大绝对 gate 为正，数值是未乘学习率的方向累计，不是参数增量。

| 项 | 可靠监督批次 / 700 | 监督向外方向和（仅可靠） | 增广向外方向和（全部） | 实际 $\lvert s\rvert$ 净变化 | 实际 $a$ 净变化 |
|---|---|---:|---:|---:|---:|
| $x_0^2$ | 695 / 700 | +121.306962 | −124.811447 | −0.011794 | +1.882036 |
| $x_1^2$ | 695 / 700 | +34.379034 | −40.488946 | −0.000447 | +1.536503 |

这支持“监督与增广方向存在拉扯，gate 并非大幅净增长”的观察，但不能把两列方向和相加当完整梯度和：监督列缺少不可靠位置，Adam 还混合了历史一阶/二阶矩和逐坐标预条件。前一窗口平方项只有 497/700 与 516/700 个可靠监督符号，更不能假装完整分解其监督贡献。

第一层列的原始监督径向下降方向累计为 +24.181063、+14.557310，对应 weight decay 径向方向为 −1.053917、−1.011071；实际列范数分别在 649/700、566/700 次更新中增大。这里记录的是欧氏方向与实际结果，**没有独立识别 Adam、weight decay、监督学习各自导致的范数增量**。本设置的增广项只约束旧 gate，不直接依赖权重列；权重变化仍会通过预测、缓存 score 与下一轮训练间接耦合。

全部 1400 个密集 minibatch 的实际 gate Adam 更新通过离线数值核对；这验证重放正确，不证明 ADMM 收敛、有限预算最优或动量必要。
