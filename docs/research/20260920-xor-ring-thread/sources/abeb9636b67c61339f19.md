# R63：同数据 XOR 与 LassoNet 训练/选择路径诊断

2026-09-16。108/108 selectors完成，零正式执行失败/重试；生命周期与独立数据、模型、读出、路径审计各108条通过。p=128/256/512，两个实例、六折、Base/Five-v1/LassoNet。

三方法使用相同内层fit、10%内层validation与外层test，scaler只fit内层fit。本轮的实际fit样本比R61/R62少10%，结果独立成表，不拼接进完整维度曲线。每维度只有两个独立数据实例，六折共享数据，不作独立样本显著性检验。

阶段首次入选、逐折差值和GRN更新次数范围内的排名，是对已保存轨迹的描述性复盘；这些汇总不构成新的成功门槛，也没有用于改变训练、调参或选择运行配置。

## 同数据不等于同训练预算

| p | 方法 | 平均实际epoch | 平均优化器更新 | 总训练秒数 |
|---:|---|---:|---:|---:|
| 128 | Base | 120.0 | 1440.0 | 113.6 |
| 128 | Five-v1 | 120.0 | 1440.0 | 143.0 |
| 128 | LassoNet | 6503.4 | 71537.6 | 4657.5 |
| 256 | Base | 120.0 | 1440.0 | 123.0 |
| 256 | Five-v1 | 120.0 | 1440.0 | 154.7 |
| 256 | LassoNet | 6256.1 | 68816.9 | 4296.9 |
| 512 | Base | 120.0 | 1440.0 | 146.7 |
| 512 | Five-v1 | 120.0 | 1440.0 | 179.4 |
| 512 | LassoNet | 6488.3 | 71371.7 | 4347.4 |

Base/Five固定20warm+100ADMM、不用验证换checkpoint；LassoNet沿原生lambda路径重复训练与验证早停，预测模型取最低内层验证损失，主特征排序用完整路径。LassoNet每epoch只取完整64样本batch，GRN还训练尾批；候选fit数据池相同，样本每epoch使用次数、网络参数化、优化器、停止和选择机制均不同。LassoNet墙钟时间还包含确定性顺序CUDA扫描的兼容实现开销，不能据此进行算法效率的公平排名。因此配对结果支持流程差异，不能单独归因为warm-up长短、ADMM或网络表达能力。

## 确定性、预核验与成本

原生LassoNet CUDA cumsum在严格确定性模式下触发预运行异常；4条完整GRN随机轨迹和1条部分随机LassoNet已保留，正式数据未受影响。私有32项顺序CUDA前缀和适配保持其余prox与优化规则；v2六条完整随机核验通过，其中LassoNet336节点、6959epochs与原生CUDA参考逐位相同。原生参考仅在随机fixture单个算子内部解除登记限制，正式运行全程严格确定性GPU；已安装包与冻结GRN源码不改。

本轮108 selectors；GRN 72×120=8640epochs，LassoNet累计 230974 epochs。累计3588+108=3696条已审计selector，其中原GRN研究线及其诊断对照3660条、LassoNet36条；以前24次refit另计，本轮没有refit。无默认晋升、原“不退化”门槛更改或追加训练。
