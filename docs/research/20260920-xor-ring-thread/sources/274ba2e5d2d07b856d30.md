# R65：冻结模型成对扰动结果

2026-09-16。用户授权的48条既有轨迹、240个固定模型状态已完成22320组确定性GPU指标评估。独立参数前向全部逐位一致；576组旧预算原始指标逐位一致，240个状态的参数与CPU/CUDA RNG不变。独立CPU核验通过全部22320组指标及21600次扰动几何。无新训练、反向更新、重拟合、benchmark数据或selector；总账仍3744。

范围是同一批p256/512的Base/Five-v1，20、120、300、600、1200轮，fit/validation/test。A/B按真实坐标索引升序；每组内部共同置换行，平方与原通道一起移动。五次固定重复先逐折平均，再平均12个重叠折；每维仅两份独立数据实例，不作显著性或独立重复推断。

## 主要发现

两类问题同时存在。256维原方法有三个Top2只命中一维的折，原测试AUROC均值0.9535，单独打乱真实A/B后分别降至0.4915/0.5201，而打乱全部噪声仍为0.9490。五项版也有一个相同类型的折，真实排名[3,1]，原0.9842，单独打乱A/B为0.5094/0.5164，打乱全部噪声为0.9828。因此这些折确实依赖两项真实输入，但gate排序没有完整反映这种依赖。

512维两方法在1200轮的真实对置换几乎不改变输出：逐折平均绝对概率变化再取12折均值，Base为0.0000781，Five为0.0000561；最高gate噪声对分别为0.3995/0.2034。这部分失败不能只解释成最后Top2截取的问题。Five的256维另11个零命中折也几乎不响应真实对，平均绝对概率变化约0.00000205。

在20轮warm结束，四个方法/维度组合的训练AUROC均约1，打乱真实对后仍约1，打乱全部噪声后为0.504–0.515。训练拟合对噪声行对应的依赖在进入ADMM前已经存在。256维Base后来在部分折形成明显真实依赖；Five只有少数折实现，512维两方法在这些检查点均未形成明显的测试判别优势。上述观察仍不单独识别某个梯度项或五项中的某一项。

## 4. 解读边界

- 两个单变量置换任一个都可能破坏XOR，所以真实对的效应不要求大于两个单变量效应之和；本报告不据此制造交互分数。
- 明显依赖真实输入但gate排名漏选，是当前函数依赖与幅值排序分离的证据，不说明替代读出已经验证有效。
- 真实对效应弱不能独自证明网络完全没有表示真信号：其他输入路径可能掩盖或抵消它。全部噪声置换提供另一项诊断，但也不是只用真实输入重训的结果。
- 输入干预只说明固定模型的依赖，不能回溯认定历史梯度、平方、WD、dropout或C某一项造成问题。
- 所有状态均为既有数据上的事后诊断；不改变原Top2、旧失败结论、checkpoint选择或默认版本，不自动触发后续训练。
